# Photo to Sketch AI 🎨

[Photo-to-Sketch.ai](https://photo-to-sketch.ai) is a free online tool that uses AI to turn your photos into beautiful line drawings and pencil sketches instantly — no editing skills required.

## ✨ Features

- 🧠 AI-powered photo-to-sketch conversion
- 📷 Works with portraits, pets, landscapes, and more
- ⚡ No installation needed — runs 100% in the browser
- 🎨 Output in clean black & white sketch format
- 💾 Free to use with fast download option

## 🚀 How It Works

1. Upload a photo (JPG, PNG, etc.)
2. The AI detects outlines, edges, and contrasts
3. It instantly converts your photo into a high-resolution sketch
4. Download and use it for art, tattoos, prints, or gifts!

## 🛠 Use Cases

- Create wall art from old photos
- Make personalized sketches for gifts
- Design tattoo ideas
- Add unique content to your social media
